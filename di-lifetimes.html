Dependency Injection Lifetimes

Three counter classes are registered with three different lifetimes. On every request, two classes ask for all three counters: a Helper class first, then the page model. Each one calls Next() once. Send a few requests and compare the numbers.

Program.cs

builder.Services.AddSingleton<SingletonCounter>();
builder.Services.AddScoped<ScopedCounter>();
builder.Services.AddTransient<TransientCounter>();

Each counter class

public class SingletonCounter { private int _n; public int Next() => ++_n; }
