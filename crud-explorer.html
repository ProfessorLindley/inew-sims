The SQL and parameter formats were captured from a real app using EF Core 10 and SQLite with this sample data. Each request uses a new DbContext, the way a scoped DbContext works in a web app. After a successful POST, the page redirects to the list, which runs the List query again; that query is left out to keep the output short. The Edit and Create pages also load the employee and certification lists for their dropdowns; those queries are left out as well.
